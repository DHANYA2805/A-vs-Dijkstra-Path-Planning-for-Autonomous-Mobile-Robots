Figure 6: Decision guideline

When should a robot use A* (Octile) instead of Dijkstra? Each cell is one of the 9 tested configurations.

Rule used: Either is fine when Dijkstra explores fewer than 3,000 cells (both finish almost instantly). Otherwise A* is recommended, and strongly recommended when it explores at least 80% fewer cells.
Dijkstra still wins when a robot needs distances to many goals at once, for example the nearest of several charging docks, because one run gives the distance to every cell.
